# 快速排座位 1.0

一个面向班级座位安排的单文件 Web App。无需安装、无需服务器，下载并打开 [`座位 1.0.html`](./座位%201.0.html) 即可使用。

1.0 由 30 个连续原型迭代而来。旧版源码保存在 [`archive/`](./archive/)，完整演进记录见 [`HISTORY.md`](./HISTORY.md)。

## 主要功能

- 分别导入男生、女生名单，并按姓名前的数字编号排序。
- 自定义 1–20 行、1–20 列的座位表。
- 在任意两列之间添加或移除过道，模拟同桌、小组等真实布局。
- 将学生拖入座位、在座位间互换，或拖回未排区；双击座位或选中后按 `Delete` / `Backspace` 也可退回。
- 把学生拖到标记区，可切换“小组长”和“爱讲话”状态。
- 支持给学生添加多个自定义标签；标签可用空格、逗号、顿号、分号、竖线或斜杠分隔。
- 提供三种座位显示方式：学号/姓名/标签三行、编号分离紧凑、编号姓名同行。
- 随机排座；若设置了组长，则要求组长人数等于真实座位列数，并保证每列一名组长。
- 显示男女未排人数、已排人数、座位容量和未排总数。
- 名单与座位表均可保存/加载为 JSON；座位文件会保存行列数、过道、性别、组长、爱讲话和标签信息。
- 导出老师视角或学生视角的制表符表格，可直接复制到 Excel / WPS。
- 导出老师视角或学生视角的 A4 横向矢量 PDF，保留过道、颜色、标记和标签。

## 快速开始

1. 下载并用最新版 Chrome、Edge、Safari 或 Firefox 打开 `座位 1.0.html`。
2. 在左右两个输入框中粘贴名单，每行一名学生，推荐格式为 `01 张三`。
3. 点击“导入男生”或“导入女生”。重复导入时，同一性别、同一文本的学生会被跳过。
4. 设置行数和座位列数，点击“重置座位表格”。需要过道时，点击第一行座位边缘的绿色 `+`；点击过道上的红色 `−` 可移除。
5. 手动拖放排座，或先设置标记和标签后点击“随机排座”。
6. 完成后保存 JSON 备份，并按需导出表格或 PDF。

> “重置座位表格”会清空当前座位；“清空座位表”会把已排学生退回未排区；“清空全部学生”会清除未排区和座位中的所有学生，并要求确认。

## 标记与多标签

- **小组长**：把学生拖到“小组长”框中即可切换；再次拖入可取消。组长以渐变底色和粗边框显示。
- **爱讲话**：把学生拖到“爱讲话学生”框中即可切换；再次拖入可取消，界面以 📣 标识。
- **自定义标签**：先在“标签内容”中填写一个或多个标签，再把学生拖入标签框。若该学生已经拥有输入框里的全部标签，本次操作会移除它们；否则会追加缺少的标签。

标记和标签既可对未排区学生操作，也可直接对已入座学生操作，并会随名单 JSON、座位 JSON 和 PDF 一起保存或导出。

## 随机排座规则

- 排座前会汇总未排区与座位中的学生，避免已入座学生遗漏。
- 未设置组长时，所有学生随机排列。
- 设置组长时，组长人数必须等于座位列数；每列随机安排一名组长，组长所在行也随机。
- 其他学生随机后从靠近讲台的一排开始填充。
- 人数超过容量时，多余学生会保留在未排区，不会丢失。
- “爱讲话”和自定义标签用于记录与展示，目前不会影响随机算法的相邻约束。

## 保存、加载与兼容性

### 名单 JSON

“保存名单”会保存所有学生（包括已入座者），字段包括姓名、性别、组长、爱讲话和标签。加载名单时会校验数据并跳过无效或重复记录。

### 座位 JSON

“保存座位表”使用版本 3 格式，保存：

- 行数与真实座位列数；
- 过道位置；
- 每位已入座学生的逻辑行列坐标；
- 性别、组长、爱讲话和标签。

1.0 也能读取旧版本直接以数组保存的座位 JSON。加载前会先完成解析与校验，坏文件不会先清空当前座位。

## 导出说明

- **表格**：结果显示在页面底部文本框中；学生视角会同时反转行列顺序。
- **PDF**：生成 A4 横向矢量文件，适合打印。学生视角同样会反转行列方向。
- PDF 功能通过 CDN 加载 jsPDF，并在首次导出时从公开字体仓库获取中文字体，因此需要网络连接。名单、拖放、排座和 JSON 保存等核心功能均在浏览器本地完成。

## 隐私

应用没有后端，也不会把名单上传到项目作者的服务器。输入内容、导入的 JSON 和排座数据只在当前浏览器页面中处理；关闭页面前请主动保存需要保留的 JSON 文件。

## 运行方式

最简单的方式是直接双击 HTML 文件。也可以在本目录启动静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000/%E5%BA%A7%E4%BD%8D%201.0.html`。
